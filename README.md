# DOT MAP APP

### Simple map application that allows the user to add a dot to a map with a description (i.e. red, orange, yellow tags). User can also delete dots, and edit them if needed.

## What does it utilize?
- Google Maps API; free version, so no charges.
- Local JSON storage of dots. So no SQLite for this simple map app.
  - Think of how Google Maps stores your "favorite" places. Rather than storing it in their cloud, this is local information you can keep for yourself.

## How to use?
- Step 1: Either have an Android phone or an emulated phone on Android Studio
- Step 2: Download / pull this repository.
- Step 3: Open in Android Studio.
- Step 4: Build Gradle on Android Studio.
- Step 5: Plug-in phone with debugging mode on, or turn on emulated phone.
- Step 6: Launch app! (or press the "play" button in the top right)
